# Teaching Experiments

Use lightweight, one-variable-at-a-time experiments.

## Candidate Dimensions

- open-ended prompt vs focused prompt
- proof-first vs counterexample-first
- more explanation vs less explanation
- blocked practice vs interleaved practice
- direct proof vs faded skeleton

## Guardrails

- one active experiment at a time when possible
- do not degrade the learning experience for experimental purity
- revert to the stronger default if the result is ambiguous

## What To Track

- solve rate
- hint depth
- retention next session
- transfer to a nearby problem
- visible frustration or visible boredom
