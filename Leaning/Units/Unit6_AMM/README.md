# Unit 6: AMM Core

Purpose:
- formalize an idealized constant-product AMM
- prove reserve, quote, and invariant-style properties
- later study fee-aware and discrete refinements

Why it matters:
- this is the first flagship DeFi protocol artifact in the book
- it should stay minimal enough to prove things cleanly, but recognizable as a
  real mechanism

Typical theorem families:
- reserve update laws
- quote/output sanity
- invariant-style inequalities
- fee-aware vs no-fee comparisons
